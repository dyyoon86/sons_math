# 3학년 수학 교실 ✏️

초등 3학년 수학(2022 개정 교육과정) 개념 배우기와 문제 풀기 웹페이지입니다.

## 내용
- **1학기**: 덧셈과 뺄셈 · 평면도형 · 나눗셈 · 곱셈 · 길이와 시간 · 분수와 소수
- **2학기**: 곱셈 · 나눗셈 · 원 · 분수와 소수 · 들이와 무게 · 그림그래프

각 단원마다
- 📖 **개념 배우기**: 그림과 예시로 설명
- ✏️ **문제 풀기**: 매번 새로 만들어지는 10문제. 틀리면 힌트를 보고 한 번 더, 두 번 틀리면 풀이를 보여 줘요
- ⭐ **별 모으기**: 9개 이상 맞으면 별 3개. 기록은 브라우저에 저장돼요
- 👨‍🏫 **가르치는 분을 위한 팁**
- ⚔️ 학기별 **보스전**(전체 복습) 모드

## 게임 요소
- 🧱 **블록 아바타**: 정답이면 점프, 오답이면 시무룩. 말풍선으로 응원해요
- 🪙 **코인**: 첫 시도 정답 +10, 두 번째 +5, 3연속 콤보 +10, 별 보너스 최대 +30
- 🆙 **레벨과 칭호**: 새싹 수학러 → 계산 탐험가 → … → 전설의 수학왕
- 🛒 **아바타 상점**: 모자·얼굴·티셔츠·바지·피부·망토/날개·펫(슬라임, 강아지, 고양이, 아기 드래곤)
- 🔊 효과음 (오른쪽 위 버튼으로 끄기)

## 실행
빌드 과정 없는 정적 사이트예요.
- 로컬: `python -m http.server` 후 http://localhost:8000
- 배포: GitHub 저장소 Settings → Pages → Branch `main` / `(root)` 선택 → `https://dyyoon86.github.io/sons_math/`

## 구조
```
index.html
style.css
js/avatar.js    블록 아바타 그림 + 상점 아이템
js/game.js      코인·레벨·효과음
js/helpers.js   공용 함수(분수 표시, 세로셈, 시계·도형 그림)
js/units1.js    1학기 단원: 개념 카드 + 문제 생성기
js/units2.js    2학기 단원
js/app.js       화면 전환, 문제 풀기, 진도 저장
```

단원 순서와 내용은 비상교육 3-1·3-2 교사용 지도서의 학기별 지도 계획을 참고했어요.
